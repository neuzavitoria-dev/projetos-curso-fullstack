 CRUD de Produtos em Python
Descrição
Este projeto é um CRUD (Create, Read, Update, Delete) de produtos, desenvolvido em Python, com o objetivo de praticar lógica de programação, estruturas de dados e interação com o usuário via terminal.
O sistema permite cadastrar, visualizar, editar e excluir produtos de forma simples e organizada.

Funcionalidades
✅ Adicionar produto (nome e preço)
📋 Listar todos os produtos cadastrados
✏️ Editar nome ou preço de um produto
❌ Excluir produto
🔁 Menu interativo no terminal
🔎 Busca de produtos sem diferenciar maiúsculas e minúsculas

Tecnologias utilizadas
Python 3
Estruturas de dados (listas e dicionários)
Controle de fluxo (while, match/case)
Git e GitHub

Como executar o projeto
Certifique-se de ter o Python 3 instalado
Clone o repositório:
git clone https://github.com/neuzavitoria-dev/curso-fullstack.git
Acesse a pasta do projeto:
cd projeto/produtos-crud

Execute o arquivo:
python crud_produtos.py
